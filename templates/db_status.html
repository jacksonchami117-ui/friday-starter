How to Enable Database Mode

To enable SQLite database persistence:

  1. Set the environment variable: USE_DB=1
  2. Restart the application
  3. Existing CSV data will be automatically migrated
  4. Database will be created at: {{ status.db_path }}

Benefits of database mode:

  • Better performance for large datasets
  • Advanced querying and analytics
  • Data integrity and relationships
  • Automatic backups and migrations

Fallback behavior: If database initialization fails, the system automatically falls back to CSV mode with user notification.
